Mounting : 
    Mounting means putting a React component into the DOM for the first time.
        - When a component is created and inserted into the DOM tree, we say it has mounted.
React Lifecycle (for functional components) :
    React lifecycle has three phases: mounting, updating, and unmounting.
        Mounting →      component is created & rendered for the first time.
        Updating →      when state/props change, component re-renders.
        Unmounting →    when the component is removed from the DOM.
    Note :
        In class components we use lifecycle methods like componentDidMount, componentDidUpdate, and componentWillUnmount. In functional components, the same behavior is handled with useEffect and its cleanup function.

Difference between package.json and package-lock.json : 
        - package.json defines the project metadata, scripts, and dependencies with flexible version ranges.
        - package-lock.json => Automatically generated when you run npm install.Contains the exact versions of every package + nested dependencies.It exact version map of all dependencies.
        - package.json is for humans, package-lock.json is for the machine.
        - package.json is created by Developer (manually) while package-lock.json is auto-generated by npm.

Single Page Application (SPA) : 
    - Single Page Application (SPA) loads a single HTML page and dynamically updates the content on that page using JavaScript without reloading the entire page.
    - Advantage of SPA: 
        - Fast Navigation
        - Better User Experience
        - Reusable component
        - Reduce Server load 

    - Disadvantage of SPA:
        - Initial load time 
        - More JS dependency.

Hooks :
    - Hooks is a normal function which is introduce with functional component. It simulates with life cycle of class based component.
    - Hooks are special functions introduced in React 16.8 that allow functional components to use features like state and lifecycle methods, and other React features without writing class components which were previously available only in class components.
    - Hooks “simulate” lifecycle behavior such as componentDidMount, componentDidUpdate, and componentWillUnmount.
    - It make functional components more powerful and reusable. 
    - It must start with use, like useState, useEffect.
